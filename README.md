# Virtual Joystick Bypass

A lightweight Windows utility for configuring a virtual joystick-style input profile, including axis selection, pitch reference, dead-zone adjustment, and optional keyboard/mouse rebinds.

## Usage

1. Download the latest ZIP from **Releases**
2. Extract the archive
3. Run `Start_Virtual_Joystick_Bypass.vbs`
4. Configure the profile and press **Run**
5. Keep the program open while the session is active

Closing the program or pressing **Stop** ends the active session.

## Requirements

- Windows 10 / 11
- PowerShell
- No installation required

If the VBS launcher does not work, use `Start_Virtual_Joystick_Bypass.cmd` instead.

See the included `README.txt` for additional information.
